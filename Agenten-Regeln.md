# Agenten-Regeln & Architektur-Vorgaben

Bitte halte dich bei allen Implementierungen an diese Richtlinien:

## Technologie-Stack
- **Framework**: Next.js (React)
- **Sprache**: TypeScript (strikte Typisierung)
- **Styling**: (Bitte hier gewünschte Styling-Lösung ergänzen, z.B. Tailwind CSS, CSS Modules)

## Allgemeine Entwicklungsrichtlinien
- **Sprache in der Kommunikation**: Immer auf Deutsch antworten (Erklärungen, Planungen etc.), Code und technische Fachbegriffe bleiben auf Englisch.
- **Komponenten**: Erstelle wiederverwendbare, modulare React-Komponenten.
- **Clean Code**: Achte auf sauberen, gut lesbaren und wartbaren Code.
- **Typisierung**: Vermeide `any` in TypeScript, definiere stattdessen explizite Interfaces oder Types.
